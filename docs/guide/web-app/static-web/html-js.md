## Esquema

- Los tres papeles: HTML es el contenido, CSS es el aspecto, JavaScript es el
  comportamiento. Mantenlos en archivos separados.
- Una página mínima que funciona: `index.html`, `style.css`, `app.js`.
- El DOM en la práctica: `querySelector`, `textContent`, `addEventListener`.
- Cargar datos sin backend: `fetch()` sobre un archivo JSON subido al
  repositorio.
- Que siga siendo legible al crecer: un script por pantalla, parciales de HTML,
  ningún framework.
- Probar una página estática en local: `python -m http.server`, y por qué abrir
  el archivo directamente no es lo mismo.
- Qué *no* hacer: nunca un secreto en el cliente. Todo lo que se publica es
  público.
