## Outline

- The three roles: HTML is the content, CSS is the appearance, JavaScript is the
  behaviour. Keep them in separate files.
- A minimal page that works: `index.html`, `style.css`, `app.js`.
- The DOM in practice: `querySelector`, `textContent`, `addEventListener`.
- Loading data without a backend: `fetch()` on a JSON file committed to the
  repository.
- Keeping it readable as it grows: one script per screen, HTML partials, no
  framework.
- Testing a static page locally: `python -m http.server`, and why opening the
  file directly is not the same thing.
- What *not* to do: no secrets in the client, ever. Everything shipped is public.
