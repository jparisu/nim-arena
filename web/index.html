    About NIM Arena

    NIM is played with several rows of sticks. On each turn you remove one or more sticks from a single row. Whoever takes the last stick wins (normal play).

    One source of truth

    The game rules and every AI are written once, in Python. This page loads that exact code through Pyodide (Python compiled to WebAssembly) — the rules are never re-implemented in JavaScript. The same code also runs the automated tournament in GitHub Actions.

    The winning strategy (X-ray mode)

    The optimal strategy uses the nim-sum: the bitwise XOR of all row sizes. If the nim-sum is non-zero, the player to move can force a win by moving to a position whose nim-sum is zero. Turn on X-ray mode during a game to see the nim-sum live and the row the perfect player would touch.
